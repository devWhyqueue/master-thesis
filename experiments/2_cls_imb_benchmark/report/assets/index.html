Dataset preparation & partition freezing
1 Prepare
  • Input: raw dataset on disk (WSIs/ROIs, labels, metadata)
  • Extract frozen Virchow2 features
  • CLS + mean patch token (2560-d)
  • Apply eligibility rules (valid target, split-unit ID, tissue rule, readable features)
  • Independently seeded
Output: feature manifest + 3 disjoint partitions
2 Pilot × 3 splits
  • Size-matched balanced CE
  • Nested support: 10 / 15 / 20 / 30 / 50 units per class
  • 3 constructions: grouped five-fold linear probes
  • kNN sensitivity; rank easiest to hardest
  • Compare natural-validation performance
Output: stability floor + signed difficulty ranking
3 Freeze × 3 splits
  • Lock min support = max(pilot floor, design floor)
  • Design floor: 10 split units / 20 slides minimum
  • Build native, difficulty-aligned, and difficulty-reversed manifests
  • Conditions: natural, balanced, moderate (ρ=10), severe (ρ=100, if feasible)
  • Shared held-out val/test sets
  • Sign pilot hashes, folds, rankings, and freeze
Output: signed manifest_freeze.json
